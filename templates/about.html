About ShopEase

A fully functional, end-to-end e-commerce web platform engineered for real-world reliability and internship evaluation.

Project Overview & Objective

ShopEase was architected to fulfill the rigorous requirements of a production-style internship project. Rather than a static prototype with mock buttons, every feature connects directly to a relational database backed by atomic transaction safety and strict input validation.

Key Architecture Highlights

  • Session & Authenticated Hybrid Cart: Anonymous guests can freely browse and add products to a session-backed cart. Upon logging in or registering, all guest items are seamlessly migrated to the user's permanent database profile.
  • Atomic Checkout & Concurrency Locking: Checkouts use Django's transaction.atomic() combined with row-level locks (select_for_update) to prevent inventory over-selling or race conditions.
  • Order Snapshots: Product prices at the exact moment of order placement are recorded into immutable OrderItem rows, guaranteeing historical integrity even if future catalog prices change.
  • Defensive Security: Full CSRF protection across all state-mutating requests, authorization checks preventing cross-user order snooping, password hashing using PBKDF2 with SHA-256, and sanitization.
  • Pure Native Styling: Clean, responsive CSS Grid and Flexbox with CSS custom properties, responsive breakpoints for mobile, tablet, and desktop without external bloated frameworks.
